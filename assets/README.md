# Project icons

The Herdr Lazyagent mark combines a relaxed sheep with a usage gauge.
All four PNGs have a square 1254 × 1254 canvas and no lettering.

| File | Use |
| --- | --- |
| [icon-transparent-light.png](icon-transparent-light.png) | Transparent mark for light surfaces, with a charcoal outline. |
| [icon-transparent-dark.png](icon-transparent-dark.png) | Transparent mark for dark surfaces, with a pale outline and brighter blue gauge. |
| [icon-light.png](icon-light.png) | Complete square icon on a light background. |
| [icon-dark.png](icon-dark.png) | Complete square icon on a dark background. |

The transparent versions have actual alpha transparency. The background
versions are fully opaque. Use the matching contrast variant when placing
the mark over another surface. The README selects its transparent mark
according to the reader's light or dark color scheme.

The badge accent **#6396CF** was sampled from the blue gauge of the light
variant. The icons were generated with the built-in ImageGen tool. The
master and edit prompts are recorded in [prompts.json](prompts.json).
